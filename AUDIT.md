# Existing application audit

The supplied ZIP contains index.html (167 KB) and README.txt. It has no package manager, framework, backend, migrations, API, or authentication. The frontend is vanilla JavaScript with inline CSS and event handlers. It uses an SVG schematic map, SVG dependency graph, CSS bar charts, modal forms, a command palette, a responsive sidebar and a dark theme. These remain the product frontend.

Pages: dashboard, digital twin/map/graph, RICE/failure simulator, priorities, budget optimizer, decision brief, reports, confidence, assets, incidents, analytics, what-if, citizen portal, settings. Data consists of generated asset arrays, synthetic reports/incidents, and localStorage. Numerous functions are duplicated; later declarations replace earlier ones. The last map renderer references an undefined oldMapRender; shell selectors incorrectly use getElementById with CSS selectors. Graph traversal is undirected and fabricates household edges. Scoring blends seed constants into computed values. Image uploads are browser data URLs. No server permissions exist.

Conversion: retain markup, CSS, navigation, modal presentation, maps and chart containers; deduplicate the renderer; replace authoritative arrays with an API snapshot; move mutations and calculations into typed services and transactional relational storage. Keep only theme/sidebar preferences in browser storage. Add session authentication, ownership/RBAC, schema validation, image re-encoding, database migrations, bounded collections, management screens, deterministic graph traversal and optimization, and integration/browser tests.

Database: PostgreSQL SQL schema; pg for a configured server, PGlite (actual embedded PostgreSQL) for local development because no PostgreSQL service is installed. Both execute the same migrations and parameterized statements. This avoids requiring Docker to demonstrate persistence while supporting a conventional PostgreSQL deployment. Parameterized repository queries are used instead of introducing an ORM over the existing untyped frontend.
